# AI-CC-Laboratory-Practice-II

A collection of Artificial Intelligence (AI) and Cloud Computing (CC) laboratory practicals and algorithm implementations using Java and Python.

---

## 📌 About Repository

This repository contains practical implementations of important AI algorithms and problem-solving techniques performed as part of Laboratory Practice-II.

The programs are implemented for learning, academic practice, and understanding algorithmic concepts in Artificial Intelligence and Cloud Computing.

---

## 🚀 Algorithms & Programs Included

### 🔹 Search Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
- A* Algorithm
- Dijkstra Algorithm

### 🔹 Minimum Spanning Tree Algorithms
- Prim's Algorithm
- Kruskal's Algorithm

### 🔹 Problem Solving Algorithms
- N-Queens Problem
- Selection Sort

### 🔹 Python Project
- Simple AI Chatbot
